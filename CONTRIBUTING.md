# Contributing

Start with an issue explaining the real household task or defect. Keep changes within the documented scope. Use a branch and pull request, include a regression test for behavioral fixes, and run `npm test`, `npm run check` and `npm run build`.

Check keyboard access, narrow screens, backup compatibility and the exact offline release package for user-facing changes. Document privacy and data-format changes. Independent review and the repository checks are required before release. Never include real household data, credentials or private photos in fixtures.
