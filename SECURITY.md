# Security

Report sensitive vulnerabilities through the repository's private security reporting when available. Do not attach personal backups or household photographs to public issues.

Storage Box Finder stores data locally without encryption. It sends no library data to a server. Imported backups are validated before replacement, with bounded fields and raster-only embedded photos. Clicking an authored link intentionally opens another site. Treat backups and printouts as private household information.

No software can guarantee permanent browser storage. Export backups regularly. Follow the recovery panel if saved bytes cannot be read.
